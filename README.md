# Template based on Arcadia Notebook Pub "From black box to glass box: Making UMAP embeddings interpretable with exact feature contributions"

This code repository contains material that is used for creating and hosting the publication entitled, *"From black box to glass box: Making UMAP embeddings interpretable with exact feature contributions"*.
The original publication is hosted at [this URL](https://arcadia-science.github.io/glass-box-umap-notebook-pub/).
